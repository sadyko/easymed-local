# coolicons — набор иконок интерфейса

Единственный набор иконок Easy-Med Local. Всё, что рисует `Icon('…')`, берётся
отсюда, и ничего не рисуется вручную: один набор на весь интерфейс.

| Файлов | 442 SVG, 24×24, обводка `currentColor`, `stroke-width="2"` |

Данные лицензии взяты из `Webfont/selection.json` авторской поставки
(`metadata.license` = `CC BY 4.0`); отдельного файла LICENSE в поставке нет,
поэтому этот файл — и есть требуемое указание авторства. **Он обязан ехать
вместе с иконками**: CC BY 4.0 разрешает использование при условии указания
автора, и в комплекте клиники (`public/` целиком попадает в релизный архив,
см. `scripts/build-bundle.mjs`) этот файл — единственное место, где оно есть.

## Что вендорится, а что нет

Из авторской поставки взята **только папка SVG**. Сознательно НЕ взяты:

- **PNG (7,5 МБ)** — растр. Он не умеет `currentColor`, то есть не может
  следовать цветовым токенам темы: иконка в тёмной шапке и та же иконка на
  светлой карточке должны быть разного цвета, а PNG всегда один и тот же.
- **Webfont (1,7 МБ)** — иконочный шрифт рисует иконку глифом в тексте. В этом
  проекте это уже стреляло: Chrome переводил русский интерфейс и ломал
  содержимое элементов (см. `admin.html`, `lang="ru" translate="no"`).
  Иконка, которая является символом текста, — ровно та поверхность, по которой
  бьёт автоперевод и подмена шрифтов расширениями браузера.
- **`.iconjar`** — формат каталогизатора для дизайнера, не ассет.

## Как добавить иконку

1. Найти нужный файл в этой папке (имена — авторские, не переименовывать).
2. Добавить строку в `public/js/admin/icon-map.js`.
3. `node scripts/build-icon-paths.mjs` — перегенерировать `icon-paths.js`.
4. `node --test public/js/admin/__tests__/icons.test.mjs` — тест свежести
   проверит, что сгенерированный файл соответствует этим SVG.
