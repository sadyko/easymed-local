# Видимость разделов меню для всей клиники (NAV_VISIBILITY_V1) — дизайн

Метка: `NAV_VISIBILITY_V1`. Маршрут `visibility-settings` (подэкран «Настроек»), миграция 254.

## Просьба владельца (2026-10-26)

Снимок хаба «Настройки → Основное» и бокового меню: «in here build visibility setting of
functions from here, only setting block can not be unvisible». То есть плитка в группе
«Основное», где администратор выбирает, какие разделы меню показывать в этой клинике; группу
«Настройки» скрыть нельзя.

## Решения

| Вопрос | Решение |
|---|---|
| Что это | Клиничная настройка, не права: скрытый раздел исчезает из бокового меню у ВСЕХ сотрудников, какие бы права у них ни были; права ролей не меняются, лицензия не меняется. Клиника без стационара снимает «Стационар», «Задачи медсестры», «Порционник», «Выписки» — и они уходят из меню у всех |
| Хранение | `nav_visibility (nav_id PK, hidden_by, hidden_at)`: строка = скрытый пункт; список скрытых = все строки. Сохранение заменяет список целиком |
| Что можно скрыть | Любой пункт `NAV` (admin.js), кроме `settings` — проверяет общая логика `nav-visibility-logic.js` (клиент и сервер), сервер отказывает 400 на `settings` и на мусорные id |
| Где прячется | Оболочка: `renderSidebar` пропускает скрытые пункты (пустая группа не рисуется — это уже так); `firstAllowedView` их не выбирает домом; `renderViewInner` по прямой ссылке показывает заглушку «Раздел скрыт» вместо экрана — для пункта и для его подэкранов (`PARENT_OF`: карта пациента прячется вместе с «Пациентами»). Подэкраны «Настроек» не прячутся никогда. Плитки хаба настроек это не трогает |
| Когда грузится | `onAuthed`: после прав, до `startApp` — меню с первой отрисовки уже без скрытых. Экран настроек после сохранения зовёт `window.easymed.setNavHidden(list)`: меню администратора перерисовывается сразу, у остальных — после перезагрузки страницы (так и написано в подтверждении) |
| Кто меняет | Только администратор: RPC `nav_visibility_save` — `isAdminUser`; маршрут — `isRouteAllowed('visibility-settings') → false` для настроенных ролей (полный доступ проходит раньше), запись в `FULL_ACCESS_ONLY`. Читать (`nav_visibility_get`) может любой вошедший — его меню от этого зависит |
| Экран | Карточка на группу меню (имя группы — перевод `sidebar.sections.*`), строка на пункт с галочкой «показывать» (имя — `sidebar.nav.*`), у «Настроек» галочка включена и заблокирована с пометкой «всегда», у скрытых — пометка «скрыт». «Сохранить» (активна при изменениях), «Показать все». Список пунктов — `window.easymed.NAV`, как у сводки прав в «Ролях»: второй копии нет |
| Что не делаем | Серверные RPC скрытых разделов не запрещаются: это видимость, не права. Скрытие по ролям — есть «Роли» |
