# «Настройки»: группы списком, свёрнуты по умолчанию (SETTINGS_HUB_LIST_V1) — дизайн

Метка: `SETTINGS_HUB_LIST_V1`. Заменяет раскладку `SETTINGS_HUB_V4` в `public/css/admin-views.css`.

## Просьба владельца (2026-10-16)

Владелец прислал снимок экрана «Настройки» — сетка 3×3 карточек, в каждой сразу все
строки. Его слова: «Change setting block design, make groups as a list and foldable,
random view is folded» — группы настроек показывать списком, каждую можно свернуть,
по умолчанию всё свёрнуто («random» прочитано как «default»).

Сессия без ответов владельца, поэтому решения ниже приняты самостоятельно и
проверяются на dev-сервере до отправки.

## Что сегодня (проверено по коду 2026-10-16, ветка `feat/stock-own-shelf-suppliers-vat`, 3.16.0)

- `renderGrid()` в `public/js/admin/views/settings-hub.js`: сетка из трёх колонок
  (две при ширине ≤1360, одна при ≤820). Группы отсортированы по числу разделов —
  только чтобы карточки в одной строке сетки были близкой высоты.
- Карточка группы: шапка (значок, название, «N разделов») и под ней сразу все строки.
- Поиск фильтрует строки и прячет группы без совпадений.
- Тесты читают хаб по классам `.set-card`, `.set-card-title`, `.set-row`,
  `.set-row-name`, `.set-row-link` — обходом дерева, без учёта видимости.

## Решения

| Вопрос | Решение |
|---|---|
| Раскладка | Один столбец: карточки групп идут списком одна под другой |
| Порядок групп | Порядок объявления в `GROUPS`. Сортировка по размеру служила сетке и уходит вместе с ней |
| Чем сворачивать | Вся шапка карточки — `<button aria-expanded>`; справа шеврон, который поворачивается у раскрытой группы. Клавиатура работает сама, потому что это кнопка |
| По умолчанию | При загрузке страницы все группы свёрнуты. Открытые пользователем группы помнятся в памяти модуля (как `hubQuery`) до перезагрузки: возврат из справочника в хаб не закрывает только что открытую группу. В `localStorage` ничего не пишется |
| Поиск | При непустом запросе каждая группа с совпадениями показана раскрытой — свёрнутые результаты поиска бесполезны. Очистили запрос — вернулось прежнее состояние |
| Строки раскрытой группы | Тоже списком: по одному разделу на строку, на всю ширину. Первый вариант раскладывал их в 3 / 2 / 1 колонки, чтобы не вернуть строку «от края до края», которую чинил `SETTINGS_HUB_V4`; владелец посмотрел на dev и попросил список и здесь (второй снимок, 2026-10-16) |
| «Развернуть все / Свернуть все» | Одна кнопка рядом с поиском: пока хоть одна видимая группа свёрнута — «Развернуть все», иначе «Свернуть все». Обе строки уже есть в `i18n-strings.js` |
| Что не меняется | Классы, по которым читают тесты; действия строк; живой статус обновления в строке «Система»; тексты строк и групп; «Скоро»-строки |

Свёрнутая группа всё равно держит свои строки в DOM (скрыты атрибутом `hidden`):
так статус обновления находит свою строку, поиск и переводчик видят текст, а
тесты читают хаб как раньше.

## Тесты (`settings-hub-fold.test.mjs`, тот же фейковый DOM, что в `settings-hub-groups.test.mjs`)

1. После монтирования у каждой группы `aria-expanded="false"`, тело скрыто; порядок
   заголовков — порядок `GROUPS`.
2. Щелчок по шапке раскрывает только эту группу; повторный — сворачивает.
3. Открытая группа остаётся открытой после повторного монтирования хаба (возврат
   из справочника).
4. Запрос в поиске раскрывает группы с совпадениями; пустой запрос возвращает
   свёрнутое состояние.
5. «Развернуть все» раскрывает всё и становится «Свернуть все»; обратно — сворачивает.
