# SOFTPHONE_V1 — телефон внутри Easy-Med: принимать и делать звонки через гарнитуру компьютера (2026-10-29)

## Почему

Панель «Телефон» (CRM_PHONE_V1, `views/crm-phone.js`) сегодня — наборник и журнал. «Позвонить» просит onlinePBX сначала поднять трубку оператора (`call/now.json`) и только потом набирает пациента. Без аппарата или приложения АТС на внутреннем номере звонок не идёт: «На этом внутреннем номере сейчас нет подключённого телефона» (снимок владельца, 2026-10-28). Входящий звонок звонит только на аппарате.

Владелец: «can we build a softphone in the easymed inside? we have one but can we use that?»

## Решения владельца (2026-10-28)

- **Режим — переключатель у каждого оператора.** «Принимать звонки в Easy-Med»: включён — звонки идут в Easy-Med (гарнитура компьютера); выключен — всё как сегодня (аппарат или приложение АТС).
- **Микрофон на адресе сети по http** — существующий файл «Настроить компьютер» (`public/setup/EasyMed-ustanovka.cmd`, PC_SETUP_INSTALL_V1). Он уже пишет политику браузера `OverrideSecurityRestrictionsOnInsecureOrigin` для адреса Easy-Med, а она открывает и микрофон, не только значок установки. https для всей сети — отдельный следующий проект.
- **Первая версия:**
  - звонок в Easy-Med с именем и картой пациента;
  - «Принять» / «Отклонить» / «Завершить»;
  - таймер;
  - выбор микрофона и динамика с проверкой;
  - «Микрофон выкл.».

  Набор цифр во время разговора, удержание и перевод — позже.
- **Номер для телефона назначает только администратор** (решение 2026-10-28 после ревью безопасности). Пароль внутреннего номера, который получает браузер, работает в любой программе-телефоне и после ухода сотрудника. Поэтому телефон Easy-Med включается только на номере, который администратор поставил в карточке сотрудника. Номер, выбранный самим оператором в «Моя трубка», работает как сегодня (звонок через аппарат, «Звонит»), но вход в АТС из браузера не даёт.

## Проверено до проектирования (2026-10-28)

- `POST /{domain}/user/get.json` с `fields:"num,name,enabled,webrtc"` (полями через запятую; массивом onlinePBX поле не отдаёт) возвращает для внутреннего номера 108: `webrtc: {host:"pbx38631.onpbx.ru:8082", user:"108", password:<32 символа>}`. Тариф клиники вход из браузера даёт.
- `wss://pbx38631.onpbx.ru:8082` отвечает `101 Switching Protocols` с подпротоколом `sip` и верным сертификатом (путь `/` подходит).

Проба только читала: база открыта на чтение, ключ АТС не обновлялся, пароль не выводился (`scratchpad/webrtc-probe/probe.mjs`).

## Устройство

- **Библиотека SIP для браузера — JsSIP** (MIT), лежит в `public/js/vendor/` своей копией, как `xlsx`: без внешних адресов, работает без интернета до АТС. Подключается одним модулем-обёрткой, чтобы её можно было заменить.
- **Сервер:** новый RPC `telephony_webrtc_me`. Данных не меняет, но при заблокированной лицензии закрыт, как и экран «Телефония» (не в `READ_ONLY_RPCS`); в журнале входа от имени — как действие.
  - Возвращает `{host, user, password, ws_url}` ТОЛЬКО для внутреннего номера самого пользователя (`users.pbx_extension`).
  - Только при праве набора (`crm.dial`, как `mayDial`) и подключённом onlinePBX.
  - При входе от имени — отказ (`sign_while_acting`-подобный текст: «Принимать звонки от чужого имени нельзя»).
  - Пароль не пишется ни в журнал, ни в базу Easy-Med; запрашивается при включении телефона и при каждой перезагрузке страницы.
  - Запрос к onlinePBX — через существующий `pbxCall` (общий ключ, ONLINEPBX_KEY_SHARE_V1).
- **Клиент:**
  - `public/js/admin/softphone.js` — жизнь телефона: регистрация, входящий, исходящий, «Принять», «Отклонить», «Завершить», «Микрофон выкл.», устройства, проверка. Без DOM, тестируется с подставным JsSIP.
  - Панель `crm-phone.js` рисует его состояния.
  - **Переключатель** «Принимать звонки в Easy-Med» запоминается только на этом компьютере (в браузере: гарнитура — у компьютера), чтобы после перезагрузки телефон поднялся сам. Миграций нет.
  - **Входящий:** панель выезжает сама, звучит звонок, показаны номер, имя пациента (как «Звонит»: по номеру), «Открыть карту», «Принять», «Отклонить».
  - **Во время разговора:** таймер, «Микрофон выкл.», «Завершить».
  - **Второй входящий во время разговора** — ответ «занято» (486); onlinePBX ведёт его дальше по своим правилам.
  - **Исходящий при включённом телефоне** — звонок прямо из браузера (INVITE на номер), без «сначала зазвонит ваша трубка». При выключенном — прежний `call/now`.
  - **Устройства:** выбор микрофона и динамика (`enumerateDevices`, `setSinkId`); «Проверить» записывает 5 секунд и проигрывает.
  - **Одна вкладка — один телефон.** Если Easy-Med открыт в двух вкладках, телефоном работает одна (выбор через BroadcastChannel); другая говорит «Телефон работает в другой вкладке».
  - **Закрыть или перезагрузить страницу во время разговора** — вопрос браузера «Идёт разговор — закрыть?» (`beforeunload`).
- **Микрофон закрыт** (не защищённый адрес, нет разрешения, нет устройства) — панель называет причину словами и что сделать: «На этом компьютере один раз запустите «Настроить компьютер»», «Разрешите микрофон в браузере», «Подключите гарнитуру».
- **Журнал, записи («Прослушать») и заявки из звонков** — без изменений: их ведёт onlinePBX, Easy-Med забирает их как сегодня.
- **Тексты** — ru/uz/en, без кириллицы в uz/en. Иконки — `Icon()`. Метка SOFTPHONE_V1.

## Чего нет в первой версии

- Binotel и «Мои Звонки».
- Набор цифр во время разговора, удержание, перевод.
- Несколько линий.
- Телефон на телефоне или планшете.
- https для всей сети клиники (следующий проект).

## Проверка

- **Тесты:**
  - `softphone.js` с подставным JsSIP (входящий: принять/отклонить; исходящий; занято; микрофон выкл.; потеря связи и повторная регистрация; одна вкладка);
  - RPC (только свой номер, право набора, отказ при входе от имени, пароль не в журнале);
  - панель (состояния, тексты ru/uz/en, кнопки в нужные моменты).
- **Браузер:** headless Chrome с подставным SIP-сервером (WebSocket) — регистрация, входящий, ответ, звук не проверяется.
- **Живая проверка с владельцем** на номере 108: входящий (принять), входящий (отклонить), исходящий, «Микрофон выкл.», качество звука.
- **Полный набор** в ru и en-US.
