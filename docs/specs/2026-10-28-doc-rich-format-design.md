# DOC_RICH_FORMAT_V1 — оформление в документе кабинета врача сохраняется; списки и таблицы (2026-10-28)

## Почему

Владелец (2026-10-28, снимок): маркированный и нумерованный списки в «Осмотре» показаны неправильно — маркеры «•» и «1.» висят левее текста, за рамкой раздела. Нужна таблица, и она должна сохраняться в шаблонах.

Корень (разбор кода, HEAD e1aba1b0):

1. **Маркеры за рамкой.** Врач пишет прямо в оформленном документе (iframe, `doc-variants.js`, `d.__editor`). Стили каждого варианта начинаются с `*{margin:0;padding:0}`, поэтому у списков нет отступа, и маркеры висят слева.
2. **Оформление не сохраняется вообще.** Жирный, цвет, подсветка и списки видны только до первой перерисовки.
   - `_syncBlankField` переносит в форму только `innerText`, экранированный.
   - `buildBlankData` пропускает каждое поле через `_blankStrip`.
   - `sec()` в вариантах рисует `esc(txt)`.
   - Разбивка на страницы (`_blankPaginatePass`) переписывает поле через `innerText`.
   - Печать, архив (`visit_documents.body`), Telegram и шаблоны получают плоский текст.
   - Таблица результата, вставленная «Вставить в документ», тоже теряется: ячейки слипаются.
   - Цвет и A+/A− теряются ещё и в очистке: `<font>` вырезается.

## Правила

- **F1. Разделы с оформлением хранят очищенную разметку.** Это разделы, которые врач пишет текстом: жалобы, анамнез, осмотр, анализы, инструментальные, рекомендации, заключение, свои разделы врача, описание и заключение диагностики. Строка «Диагноз» остаётся простым текстом.
  - Очистка — общая `shared/rich-text.js` (`sanitizeStoredHtml`): она работает без DOM и на сервере (Telegram).
  - Прежние записи простым текстом показываются как раньше (`pre-wrap`, без разметки).
- **F2. Оформление проходит весь путь без потерь:** ввод в документе → форма → сохранение (`notes`) → открытие → перерисовка → печать → архив (`visit_documents.body`) → Telegram → шаблоны («Из текущего документа» и «Использовать»).
  - Текстовые места остаются текстом и получают текст без тегов, а не экранированную разметку: `visits.conclusion`, строка диагноза, журналы, `dxParts`, сводка «снимка», `fillServiceConclusion`.
  - `_parts.push(esc(...))` с двойным экранированием `<br>` исправляется.
- **F3. Списки показаны правильно** во всех вариантах документа (заключение classic/compact, диагностика classic/compact) и в печати: отступ слева, маркеры внутри раздела. Правило стоит в стилях самих вариантов и перебивает `*{padding:0}` специфичностью. Списки рекомендаций `ul.recs` не меняются.
- **F4. Цвет и размер шрифта сохраняются.**
  - В iframe включается `styleWithCSS`: цвет и размер ложатся `style`, а не `<font>`.
  - Очистка пропускает `font-size` только из набора ключевых слов (`x-small` … `xx-large`) и `text-decoration-line`.
  - Прежние `<font color|size>` очистка переводит в `span style` (цвет — только `#hex`/`rgb()`/имя; размер — по таблице 1–7 → ключевые слова).
- **F5. Разбивка на страницы понимает разметку.**
  - Поле с разметкой делится по блокам: верхние дети поля; у `ul`/`ol` — по `li` (продолжение — тот же вид списка, нумерация продолжается: `start`); у `table` — по строкам `tr`, а строка заголовка повторяется на новой странице.
  - Блок, который не влезает целиком, переносится на следующую страницу; абзац простого текста делится как раньше.
  - Слияние продолжений возвращает узлы, а не `innerText`.
  - Положение курсора сохраняется (метка в DOM, не смещение по тексту).
  - Простой текст делится прежним алгоритмом.
- **F6. Таблица.**
  - Кнопка «Таблица» в панели оформления: выбор строк × столбцов (до 15 × 8). Вставляется `table.a4-tbl`, первая строка — заголовок (`th`).
  - Курсор в таблице — рядом панель: «+ строка», «+ столбец», «− строка», «− столбец», «Удалить таблицу».
  - `Tab` / `Shift+Tab` — следующая / предыдущая ячейка; `Tab` в последней ячейке добавляет строку.
  - Объединения ячеек нет (решение владельца — «простая таблица»).
  - Печать — тонкие рамки; на экране — те же.
  - Очистка пропускает класс `a4-tbl` (и прежний `a4-restbl`).
  - Таблица сохраняется в документе, архиве и шаблонах и делится по страницам по F5.
- **F7. Вставка результата анализа** («Вставить в документ», `a4-restbl`) сохраняется таблицей по тем же правилам.
- **F8. Пустота.** Раздел, где нет текста (только пустые теги), считается пустым (`richIsEmpty`). Ячейки таблицы при переводе в текст разделяются табуляцией, строки — переводом строки.

## Не меняется

- Строка «Диагноз» и МКБ-10.
- Порядок разделов, их добавление и удаление.
- Подпись и переподпись (правила `RESIGN_FIELDS` берут текст без тегов).
- Редактор стационара (`case-doc-a4.js`, уже хранит разметку). Его печать получает CSS списков и таблиц, если его нет.
