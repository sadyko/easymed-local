# Журналы в «Отчётах» (JOURNALS_V1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** в «Отчётах» два журнала группы прав «Журналы»: «Журнал услуг» (выбранные из списка услуги, стационар / амбулатория, кто направил, диагноз при направлении, заключение) и «Реестр стационарных пациентов» (с суммой и датой оплаты и классом палаты); у палаты появляется класс Люкс / Полулюкс / Обычная; у любого табличного отчёта — кнопка «Печать».

**Architecture:**
- **База:** миграция 234 — `wards.ward_class` (только `ADD COLUMN`, `CHECK`, без значения по умолчанию); миграция 235 — права группы «Журналы» штатным ролям (кассир и склад — «Нет», главный врач — «Просмотр»).
- **Сервер:** два новых вида `run_report` в `server/services/rpc/reports.js` — `inpatient_register` и `service_journal`. Решения без базы (выбор услуг, «одна работа», номер пациента, цепочки «кто направил» / диагноз / заключение) — в чистом `server/services/domain/journal-rules.js` с таблицей примеров. Деньги и диагноз госпитализации — фрагменты SQL в `server/services/domain/admission-facts.js`, их же читает вкладка «Госпитализации» (`admissions-register.js`). Права — `REPORT_GROUP` + окно `reports.journals` в справочнике.
- **Экран:** две карточки в `REPORT_DEFS`, новый тип опции `services` (окно `report-service-picker.js` с поиском, галочками, «Выбрать все найденные» и выбором, запомненным в `localStorage`), пилюли `kind_of_care`; класс палаты в окне палаты (`rooms-setup.js`, подписи — `public/js/shared/ward-class.js`); «Печать» — чистый `report-print.js` строит страницу из уже полученного ответа.

**Tech Stack:** Node 24 ESM, better-sqlite3 (JSON1: `json_each`, `json_extract`, `json_patch`), express, `node:test`; клиент — ванильный JS без сборки, поддельный DOM в тестах видов, SheetJS для Excel.

**Спецификация:** `docs/specs/2026-10-02-journals-design.md` (коммит `c9e61b9`) — договор.

## Решения плана (проверено по коду 2026-10-02)

1. **Статусы строки визита «прошла кассу».** Словарь `visit_services.status`: `added` (смета) → `queued` (касса: `billing.js:1088/1652/1918/2408`) → `collected`, `in_progress`, `resulted`, `completed` (миграция 041; лаборатория `laboratory.js:1125/1203`; процедуры `procedures.js:36` — `added/queued/in_progress/completed`; консультации `consultation.js:1181`, подпись `service-workspace.js:3781` — `completed`), плюс `cancelled` (отмена). Других статусов после кассы у строк визита нет — список спецификации верен: берётся сам `LAB_RESULT_STATUSES` (`server/services/visit-status-guard.js:47`). Отпущенная с возвратом строка возвращается в `added` (`cashier.js:700`). Дополнительно не показываются строки визита `cancelled`/`no_show` (`LIVE_VISIT_SQL`) и строки, связанные со счётом `refunded` (спецификация: «возврат не показывается»).
2. **Стационар по дню.** У госпитализации `admitted_at NOT NULL DEFAULT now` (миграция 091) — у заявки `ordered` это время заявки, а у отменённой нет `discharged_at` («открыта навсегда»). Поэтому «шла госпитализация» = статус из `IN_BED_STATUSES` + `discharged` (`public/js/shared/admission-status.js:25`), местный день `admitted_at` ≤ D, `discharged_at` пусто или его местный день ≥ D; несколько — последняя по `admitted_at`, затем по id.
3. **Строка случая.** «Условие как у отчётов по стационару» в спецификации названо `isInpatientLine`, но это только признак строки (`reports.js:3866`). Условие отмены берём из `IN_MEDICAL_SQL`/`IN_DONE_SQL` (`reports.js:520-525`) без требования «Выполнено» и врача: услуга (не товар, не койко-дни `ACCOMMODATION%`), `billable = 1`, госпитализация не `cancelled`, счёт строки не `refunded`. Снятая строка удаляется физически (`inpatient.js:62`, `treatment-orders.js:738`) — флага нет. Дата — местный день `performed_at`, иначе `created_at`.
4. **Без двойного счёта.** Ключ — пациент + услуга + местный день. Если есть строка визита, убираются ВСЕ строки случая с этим ключом; строка визита без своей госпитализации получает случай убранной строки (строка случая — всегда стационар).
5. **«Кто направил».** Стационар — лечащий (`admissions.attending_doctor_id`), иначе «Стационар». Амбулатория — ближайшая рекомендация `recommended_services` той же услуги и пациента, местный день ≤ дня визита, статус не `cancelled` (её снимают кнопкой «Удалить», `service-workspace.js:2639`), имя — `users.full_name`, иначе `recommended_by_name`; затем `visits.referral_source_id` → `referral_sources.name`; иначе «сам». Нижней границы у рекомендации нет — спецификация говорит «ближайшая».
6. **Диагноз при направлении.** Стационар — `admission_diagnosis`, иначе последний опубликованный непустой `admission_reviews.diagnosis` — тот же фрагмент, что у вкладки (`ADMISSION_REVIEW_DIAGNOSIS_SQL`). Амбулатория — врач направившего: `recommended_by` или `referral_sources.doctor_id` (миграция 122: у каждого врача свой источник, триггер `referral_sources_for_new_doctor`); документ `visit_documents` `doc_type = 'protocol'`, `voided_at IS NULL`, тот же пациент, местный день в [D − 30; D], врач документа = врач его строки (`visit_services.doctor_id`), иначе подписавший (`created_by` — админ подписывает за врача, `patient-card.js:666`). Текст: основной диагноз из `body.diagnoses` (`type = 'main'`, «код — название», как `_mainDxText` в `service-workspace.js:4751`), иначе `body.dx` (= `primary_diagnosis`, иначе тот же основной — `buildBlankData`, `service-workspace.js:4775`). Поле надёжно: протокол — снимок `buildBlankData`, `dx` в нём есть всегда.
7. **Заключение.** Последний неотозванный `visit_documents` строки (`visit_service_id`, `doc_type IN ('diag','protocol')`): `conclusion` → `conclusionText` → `dx` → `description` (`diag`: `{description, conclusion}`, `service-workspace.js:3797`; `protocol`: снимок с `conclusionText`, `dx`). Тело читается `json_extract` под `json_valid` — у `diag` в теле снимки base64, целиком их не грузим, битое тело даёт пусто, а не 500. На экране — до 300 знаков (клиент), в Excel и печати — целиком.
8. **Транспорт `service_ids`.** `run_report` идёт через пул (`report-pool.js:28`); аргументы клонируются JSON (`report-pool.js:147`) — массивы проходят, как уже проходит `branch_ids`. Тело RPC ограничено 2 МБ (`server/app.js:68`). В SQL — один параметр `json_each(?)`, не 2000 знаков `?`. Предел 2000 проверяется до очистки; мусор (не целые > 0) отбрасывается; неизвестные id просто не находят строк.
9. **Без колонки «Здание» у журналов.** Колонки — по бумажному журналу владельца (спецификация). Фильтр зданий и филиалов работает, разрез по зданиям — плашками над таблицей. Тест `reports-hub-v2` (первая колонка «Здание») освобождает два вида журналов.
10. **Реестр.** Строки — статус не `ordered` и не `cancelled` (отменённая госпитализация в годовой реестр не входит), местный день `admitted_at` в периоде. «Отделение» — `admissions.department`, иначе отделение палаты (без имени палаты и класса — у класса своя колонка). Палата — палата койки (`admissions.bed_id → beds.ward_id`), иначе `admissions.ward_id`; `bed_id` после выписки не стирается. «Дата оплаты» — местный день последнего платежа с `amount > 0` по живым счетам госпитализации.
11. **Права.** Окно `reports.journals` («Журналы») в разделе «Отчёты», уровни «Нет / Просмотр», прежнее правило — как у групп (`gate-fallbacks.js:99`: администратор или раздел «Отчёты»). Миграция 235 (по образцу 179 и 152): штатным `cashier` и `inventory` (у них «Отчёты» ради кассы и склада, группы записаны 179-й) — «Журналы: Нет»: диагнозы и паспорта им не нужны; штатному `head_doctor` (раздела «Отчёты» нет) — «Журналы: Просмотр»: медицинские журналы — его. Своих ролей клиники миграция не трогает; уже записанный ключ — тоже.
12. **Класс палаты.** `wards` между зданиями не ездит (нет ни в `SHIPPED` `branch-sync/journal.js:52`, ни в справочнике `branch-sync/catalogue.js:64`) — синхронизацию не трогаем. Класс — не деньги: `ward_class` в `grantColumns.wards` «Помещений», его пишет и «Помещения: Изменение».
13. **Переводы «Люкс».** Ключ «Люкс» в словаре уже есть (`i18n-strings.js:8762`, en «VIP» — класс койки `ward-beds.js:1191`); дублировать ключ нельзя (поздний молча перекрыл бы ранний), поэтому en показывает «VIP / Semi-lux / Standard», а не «Lux / Semi-lux / Standard» спецификации.
14. **Печать.** Печатается то, что перечислено в спецификации: заголовок (с видом, если у карточки видов несколько), «Период: дд.мм.гггг — дд.мм.гггг», здания или филиалы — если выбрано собственное подмножество в момент запроса, все строки, итог. Примечания не печатаются.
15. **Окно выбора услуг — новое и маленькое.** `service-picker-modal.js` — мастер регистратуры (3800 строк, заводит визит), а не множественный выбор; поиск берём общий — `service-search.js filterServicePool`.

```js
/** Не больше стольких услуг в одном журнале (тот же предел у окна выбора). */
export const JOURNAL_SERVICE_MAX = 2000;
export const KINDS_OF_CARE = Object.freeze(['all', 'inpatient', 'outpatient']);
export const SELF_REFERRED = 'сам';
export const INPATIENT_REFERRER = 'Стационар';
export const GENDER_RU = Object.freeze({ male: 'Муж.', female: 'Жен.' });
/** Сколько дней назад ищется подписанная консультация направившего врача. */
export const CONSULT_DX_DAYS = 30;

/**
 * Выбор услуг журнала → { error: null | 'empty' | 'too_many', ids }.
 * Предел проверяется на присланном массиве — до разбора; мусор (не целые > 0)
 * отбрасывается; повторы — один раз. Числа строкой принимаются (<select>).
 */
export function parseServiceIds(raw) {
  if (Array.isArray(raw) && raw.length > JOURNAL_SERVICE_MAX) return { error: 'too_many', ids: [] };
  const ids = [];
  const seen = new Set();
  for (const v of Array.isArray(raw) ? raw : []) {
    const n = typeof v === 'number' ? v : (typeof v === 'string' && /^\s*\d+\s*$/.test(v) ? Number(v) : NaN);
    if (Number.isSafeInteger(n) && n > 0 && !seen.has(n)) { seen.add(n); ids.push(n); }
  }
  return { error: ids.length ? null : 'empty', ids };
}

/** Тип: пусто — «все»; иначе одно из трёх значений, прочее — null (отказ). */
export function parseKindOfCare(raw) {
  if (raw === undefined || raw === null || raw === '') return 'all';
  return KINDS_OF_CARE.includes(raw) ? raw : null;
}

export const genderWord = (g) => (Object.prototype.hasOwnProperty.call(GENDER_RU, g) ? GENDER_RU[g] : '');

/** 'ГГГГ-ММ-ДД' минус N дней (календарь, без часовых поясов); мусор — ''. */
export function dayMinus(ymd, days) {
  const t = Date.parse(String(ymd || '').slice(0, 10) + 'T00:00:00Z');
  return Number.isFinite(t) ? new Date(t - days * 86400000).toISOString().slice(0, 10) : '';
}

const lineKey = (l) => l.patient_id + '|' + l.service_id + '|' + l.day;

/**
 * Без двойного счёта: строка визита (src 'vs') и строка случая (src 'as') с
 * тем же пациентом, услугой и местным днём — одна работа. Остаётся строка
 * визита (у неё есть заключение), строки случая с этим ключом убираются.
 * Строка визита без своей госпитализации получает случай убранной строки:
 * строка случая — всегда стационар.
 */
export function dedupeJournalLines(lines) {
  const visitKeys = new Set(lines.filter((l) => l.src === 'vs').map(lineKey));
  const caseOf = new Map();
  for (const l of lines) {
    if (l.src === 'as' && visitKeys.has(lineKey(l)) && !caseOf.has(lineKey(l))) caseOf.set(lineKey(l), l.admission_id);
  }
  const out = [];
  for (const l of lines) {
    if (l.src === 'as' && visitKeys.has(lineKey(l))) continue;
    out.push(l.src === 'vs' && l.admission_id == null && caseOf.has(lineKey(l)) ? { ...l, admission_id: caseOf.get(lineKey(l)) } : l);
  }
  return out;
}

/** Порядок журнала: дата, затем ФИО, затем услуга; дальше — строка визита раньше и по номеру. */
export function sortJournalLines(lines, compare) {
  const byText = (a, b) => (a < b ? -1 : a > b ? 1 : 0);
  return [...lines].sort((a, b) => byText(String(a.day || ''), String(b.day || ''))
    || compare(a.patient, b.patient) || compare(a.service, b.service)
    || (a.src === b.src ? 0 : a.src === 'vs' ? -1 : 1)
    || (Number(a.line_id) || 0) - (Number(b.line_id) || 0));
}

/** «Ич. рақам»: номер пациента по первому появлению в журнале — у одного пациента один номер. */
export function patientOrdinals(lines) {
  const seen = new Map();
  return lines.map((l) => {
    if (!seen.has(l.patient_id)) seen.set(l.patient_id, seen.size + 1);
    return seen.get(l.patient_id);
  });
}

/** Рекомендации по ключу «пациент|услуга» в порядке запроса (новые сначала). */
export function indexRecommendations(recs) {
  const map = new Map();
  for (const r of recs || []) {
    const k = r.patient_id + '|' + r.service_id;
    if (!map.has(k)) map.set(k, []);
    map.get(k).push(r);
  }
  return map;
}

/**
 * «Кто направил» → { text, doctorId }. Стационар — лечащий врач случая, иначе
 * «Стационар». Амбулатория — ближайшая рекомендация этой услуги этому пациенту
 * не позже дня визита (с именем), иначе источник направления визита, иначе
 * «сам». doctorId — врач направившего (для диагноза консультации) или null.
 */
export function referrerOf(line, recIndex, adm) {
  if (line.admission_id != null) {
    const name = String((adm && adm.attending) || '').trim();
    return { text: name || INPATIENT_REFERRER, doctorId: name ? (adm.attending_doctor_id ?? null) : null };
  }
  const recs = (recIndex && recIndex.get(line.patient_id + '|' + line.service_id)) || [];
  const rec = recs.find((r) => String(r.day || '') <= String(line.day || '') && String(r.name || '').trim());
  if (rec) return { text: String(rec.name).trim(), doctorId: rec.doctor_id ?? null };
  const source = String(line.visit_source || '').trim();
  if (source) return { text: source, doctorId: line.visit_source_doctor_id ?? null };
  return { text: SELF_REFERRED, doctorId: null };
}

/**
 * Диагноз подписанной консультации: основной из body.diagnoses («код —
 * название», как _mainDxText кабинета врача), иначе body.dx (= primary_diagnosis
 * или тот же основной — buildBlankData). diagnoses приходит JSON-текстом
 * (json_extract) или массивом.
 */
export function diagnosisOfBody(doc) {
  let list = doc && doc.diagnoses;
  if (typeof list === 'string') { try { list = JSON.parse(list); } catch { list = null; } }
  const main = Array.isArray(list)
    ? list.find((d) => d && d.type === 'main' && (String(d.code || '').trim() || String(d.name || '').trim()))
    : null;
  if (main) {
    const code = String(main.code || '').trim();
    const name = String(main.name || '').trim();
    return code && name ? code + ' — ' + name : (code || name);
  }
  return String((doc && doc.dx) || '').trim();
}

/** docs — подписанные консультации пациентов, новые сначала: { patient_id, doctor_id, day, text }. */
export function consultDiagnosis(docs, patientId, doctorId, day) {
  if (doctorId == null) return '';
  const lo = dayMinus(day, CONSULT_DX_DAYS);
  const d = (docs || []).find((x) => x.patient_id === patientId && Number(x.doctor_id) === Number(doctorId)
    && String(x.day) <= String(day) && String(x.day) >= lo && x.text);
  return d ? d.text : '';
}

/** «Диагноз при направлении» строки журнала. */
export function referralDiagnosis(line, adm, ref, docs) {
  if (line.admission_id != null) return admissionDiagnosisText(adm && adm.admission_diagnosis, adm && adm.review_diagnosis);
  return consultDiagnosis(docs, line.patient_id, ref && ref.doctorId, line.day);
}

// Заключение подписанного документа: у заключения диагностики (doc_type
// 'diag') — conclusion, иначе description; у протокола ('protocol') —
// conclusionText, иначе dx (service-workspace.js handleSignFinalize).
const CONCLUSION_FIELDS = ['conclusion', 'conclusionText', 'dx', 'description'];
export function conclusionOfDoc(doc) {
  for (const k of CONCLUSION_FIELDS) {
    const v = doc ? doc[k] : null;
    const s = String(v == null ? '' : v).trim();
    if (s) return s;
  }
  return '';
}
```

```js
           COALESCE(NULLIF(u.full_name, ''), NULLIF(r.recommended_by_name, '')) AS name
      FROM recommended_services r
      LEFT JOIN users u ON u.id = r.recommended_by
     WHERE r.patient_id IN (SELECT value FROM json_each(?))
       AND r.service_id IN (SELECT value FROM json_each(?))
       AND COALESCE(r.status, '') <> 'cancelled'
```

```js
// заголовок, период, здания или филиалы (если выбрано подмножество), ВСЕ
// строки (не 300 предпросмотра) и итог — те же складываемые колонки и та же
// строка «Итого», что у Excel (reportSheets). Колонок больше 8 — альбомный лист.
//
// Модуль чистый: язык экрана приходит словарём tx ({ tr, trf, lang,
// monthName } — как у report-totals.js), окно открывает вызывающий. Данные
// клиники экранируются; HTML из данных не вставляется никогда.
import { reportSheets } from './report-totals.js?v=rt3';
import { PRINT_FONT_FACE_CSS, PRINT_FONT_STACK } from '../../shared/print-fonts.js';   // ONEST_TYPOGRAPHY_V1 — семейство печати

/** Колонок больше — лист альбомный. */
export const PRINT_PORTRAIT_MAX_COLS = 8;

const esc = (s) => String(s == null ? '' : s).replace(/[&<>"']/g, (c) => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c]));

/** 'ГГГГ-ММ-ДД…' → 'дд.мм.гггг'; прочее — как есть. */
export function dmy(ymd) {
    const m = /^(\d{4})-(\d{2})-(\d{2})/.exec(String(ymd || ''));
    return m ? m[3] + '.' + m[2] + '.' + m[1] : String(ymd || '');
}

// Размеры печатного листа — бумажные метрики в pt: шкала экрана (12.5…40 px)
// к печати не относится (TYPE_SCALE_V1, исключение для печатных документов).
/* type-scale-exempt-start: печатный лист отчёта — бумажные метрики (pt), шкала экрана к печати не относится */
const PRINT_CSS = `
body { font-family: ${PRINT_FONT_STACK}; color: #111; margin: 0; }
h1 { font-size: 14pt; margin: 0 0 3pt; }
.rp-sub { font-size: 9pt; color: #444; margin: 0 0 8pt; }
.rp-tbl { width: 100%; border-collapse: collapse; font-size: 8pt; }
.rp-tbl th { text-align: left; border-bottom: 1.2pt solid #333; padding: 3pt 4pt; font-weight: 700; vertical-align: bottom; }
.rp-tbl td { border-bottom: 0.5pt solid #ccc; padding: 3pt 4pt; vertical-align: top; overflow-wrap: anywhere; }
.rp-tbl .num { text-align: right; white-space: nowrap; font-variant-numeric: tabular-nums; }
.rp-tbl tfoot td { font-weight: 800; border-top: 1.2pt solid #333; border-bottom: 0; }
tr { page-break-inside: avoid; break-inside: avoid; }
thead { display: table-header-group; }
`;
/* type-scale-exempt-end */

/**
 * Печатная страница отчёта.
 * @param {object} r     ответ run_report ({ columns, rows, summable_columns, total_skip_rows, … })
 * @param {object} meta  { title, from, to, places: { kind: 'buildings'|'branches', list: [подписи] } }
 * @param {object} tx    { tr, trf, lang, monthName }
 */
export function reportPrintHtml(r, meta, tx) {
    const res = r || {};
    const m = meta || {};
    const rows = res.rows || [];
    const [head, ...rest] = reportSheets(res, tx).report;
    const body = rest.slice(0, rows.length);
    const totals = rest.length > rows.length ? rest[rows.length] : null;
    const isNum = head.map((_, ci) => {
        const probe = rows.find((x) => x[ci] != null && x[ci] !== '');
        return typeof (probe && probe[ci]) === 'number';
    });
    const cell = (v, ci) => {
        if (v == null || v === '') return '';
        return isNum[ci] && typeof v === 'number' ? esc(Number(v).toLocaleString('ru-RU')) : esc(v);
    };
    const td = (v, ci) => `<td${isNum[ci] ? ' class="num"' : ''}>${cell(v, ci)}</td>`;
    const period = tx.trf('Период: {from} — {to}', { from: dmy(m.from), to: dmy(m.to) });
    const list = m.places && Array.isArray(m.places.list) ? m.places.list : [];
    const places = list.length
        ? tx.trf(m.places.kind === 'branches' ? 'Филиалы: {list}' : 'Здания: {list}', { list: list.join(', ') })
        : '';
    const orientation = head.length > PRINT_PORTRAIT_MAX_COLS ? 'landscape' : 'portrait';
    return `<!doctype html><html lang="${esc(tx.lang || 'ru')}"><head><meta charset="utf-8">
<title>${esc(m.title || '')}</title>
<style>
${PRINT_FONT_FACE_CSS}
@page { size: A4 ${orientation}; margin: 10mm; }
${PRINT_CSS}
</style></head><body>
<h1>${esc(m.title || '')}</h1>
<p class="rp-sub">${esc(period)}${places ? ' · ' + esc(places) : ''}</p>
<table class="rp-tbl">
<thead><tr>${head.map((c, ci) => `<th${isNum[ci] ? ' class="num"' : ''}>${esc(c)}</th>`).join('')}</tr></thead>
<tbody>${body.map((row) => `<tr>${row.map(td).join('')}</tr>`).join('\n')}</tbody>
${totals ? `<tfoot><tr>${totals.map((v, ci) => (ci === 0 ? `<td>${esc(v)}</td>` : td(v, ci))).join('')}</tr></tfoot>` : ''}
</table>
<script>window.onload = function () { (document.fonts && document.fonts.ready ? document.fonts.ready : Promise.resolve()).then(function () { try { window.focus(); window.print(); } catch (e) {} }); };</scr` + `ipt>
</body></html>`;
}
```

```js
// server/index.js). Копия — онлайн-копией SQLite (backup), dev не трогается.
// Запуск: node jrn-devcopy.mjs <каталог-копии> [порт]
import fs from 'node:fs';
import path from 'node:path';
import { createRequire } from 'node:module';
import { pathToFileURL } from 'node:url';

const REPO = 'C:/Users/user/Desktop/implementation workflow/easymed.local';
const OUT = process.argv[2];
const PORT = Number(process.argv[3] || 18733);   // вне динамического диапазона 1024–14999
if (!OUT) { console.error('usage: node jrn-devcopy.mjs <dir> [port]'); process.exit(2); }
const require = createRequire(path.join(REPO, 'package.json'));
const Database = require('better-sqlite3');
fs.mkdirSync(OUT, { recursive: true });
const src = new Database(path.join(REPO, 'data', 'easymed.db'), { readonly: true, fileMustExist: true });
await src.backup(path.join(OUT, 'easymed.db'));
src.close();
for (const f of ['licence.dat', 'control.json']) {
  const from = path.join(REPO, 'data', f);
  if (fs.existsSync(from)) fs.copyFileSync(from, path.join(OUT, f));
}
const mod = (p) => import(pathToFileURL(path.join(REPO, p)).href);
const { openDb } = await mod('server/db/connection.js');
const { migrate } = await mod('server/db/migrate.js');
const { createApp } = await mod('server/app.js');
const { setDataDir } = await mod('server/services/control/config.js');
const { configureReportPool } = await mod('server/services/report-pool.js');
setDataDir(OUT);
const db = openDb(path.join(OUT, 'easymed.db'));
migrate(db);   // 234 и 235 — на копии
console.log('pool:', configureReportPool({ db, dbFile: path.join(OUT, 'easymed.db'), dataDir: OUT }));
createApp(db, { dataDir: OUT }).listen(PORT, '127.0.0.1', () => console.log('dev copy: http://127.0.0.1:' + PORT));
```
