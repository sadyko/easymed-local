# CRM, календарь и регистрация — одна система (CRM_UNIFY_V1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** карточка CRM сама узнаёт о записи и о приходе пациента, где бы его ни записали или ни зарегистрировали; доска показывает все открытые карточки с настоящими числами; есть фильтр «Оператор»; задачи видны списком и идут за карточкой; застрявшие карточки исправляются один раз при обновлении.

**Architecture:** один серверный шаг `crmLinkVisit` (новый `server/services/crm/visit-link.js`) после любой записи и регистрации заменяет два прежних пути (`settleCrmOnBooking` в `rpc/visits.js` и `attachVisitToCrm` в `crm/booking-mirror.js`). Регистрация на стойке присылает `desk: true`, и шаг закрывает карточку в «Пришёл». «Колонка записи» и окно 72 часа — настройки «CRM-канбан» в новой таблице `crm_settings` (миграция 237); правило колонки — одна чистая функция для сервера и браузера (`public/js/shared/crm-booked-stage.js`). «Не пришёл» ставит сервер (`crm/no-show.js`, при запуске и раз в час). Доска грузится через `/api/db` (новый `views/crm-board-load.js`): все открытые, закрытые — за период. Задачи: `crm/tasks-follow.js` (идут за карточкой, исполнитель обязан видеть карточку, RPC `crm_task_assignees`), вид «Задачи» (`views/crm-tasks-view.js`). Разовое исправление — `crm/unify-repair.js`, запускается при первом старте после миграции 238.

**Tech Stack:** Node 24 ESM, express, better-sqlite3, `node:test`; клиент — ванильный JS без сборки, поддельный DOM в тестах видов.

## Решения плана (там, где дизайн оставил выбор)

| № | Решение | Почему (одна строка) |
|---|---|---|
| Р1 | «Регистрация на стойке» сигналится явным `desk: true` в `ensure_visit`. Его присылает только `registerWalkIn` (быстрая регистрация / «пришёл сейчас»). Сервер принимает его только от admin/registrar, только без `book` и только если день визита — сегодня по местному времени. | «Сегодня без `book`» шлют ещё карточка CRM (врач с живой очередью) и мастер визита (строки «на дату») — это запись, а не приход. |
| Р2 | «Последнее движение карточки» для окна — `crm_requests.updated_at` (нет — `created_at`). | Его уже двигает каждый писатель: компилятор при любой правке через `/api/db` и каждый серверный переход. Звонок и задача — не движение карточки. |
| Р3 | Открытая карточка после окна возвращается в первую открытую видимую колонку по порядку (у клиники — «Новый лид»). | Это начало доски, новой настройки не нужно. |
| Р4 | Окно действует на входящий звонок и на запись. Исходящий звонок — как сегодня: карточка только у номера без единой карточки, существующую не двигает. | Исходящий звонок — работа оператора с карточкой, а не новое обращение пациента. |
| Р5 | Закрытая карточка в пределах окна + новый звонок или запись: новой карточки нет, закрытую не трогаем, привязки записи к ней нет. | Решение 3 (закрытая не открывается) + «без дублей». |

Пишется только `patient_id` и ступень. Ни строк, ни `visit_id`, ни `crm_booking_links`. | Правило риска дизайна; второй номер считается, чтобы общий семейный номер никогда не был «номером одной карты». |
| Р7 | Какие карточки берёт запись:<br>(A) карточки пациента, чьи строки этого дня взяли визит;<br>(B) карточка, уже держащая визит;<br>(C) открытые карточки пациента, ждущие этот приход, — любой роли и любой давности (на стойке — все открытые);<br>(D) по телефону;<br>(E) только «чистый» колл-центр: свежая открытая карточка, иначе новая. | Сводит вместе `settleCrmOnBooking` (заявки без строк любой давности) и `attachVisitToCrm` («ждёт этот день»). Карточку, ждущую ДРУГОЙ день, запись не двигает (так закреплено в `visits.test.js`). |
| Р8 | Первый приход закрывает карточку в «Пришёл», даже если остались строки на другие дни. Приход закрывает живые колонки и сидовую «Не пришёл»; «Пришёл», «Отказ» и прочие закрытые не трогает. | Решения 1 и 3; «воскрешение» «Не пришёл» приходом — сегодняшнее правило. |
| Р9 | Приход закрывает и карточку, привязанную к визиту только записью (`crm_booking_links`, без строк). | Иначе запись из календаря без строк заявки не закрывается, если дата карточки другая. |
| Р10 | «Колонка записи» хранится в новой таблице `crm_settings` (этой установки, соседям не ездит). Выбор, ставший недопустимым (колонку скрыли, удалили или поставили после «Пришёл»), молча заменяется правилом по умолчанию. // CRM_UNIFY_V1 (2026-10-09) — ОДНА ТОЧКА СВЯЗИ ВИЗИТА С CRM
// ═══════════════════════════════════════════════════════════════════════════
//
// Владелец: «объединить календарь, CRM и регистрацию». До этого файла визит
// находил заявку ДВУМЯ путями с разными правилами: ensure_visit
// (settleCrmOnBooking — строки дня и любые заявки без строк) и calendar_book /
// booking_lines_add (attachVisitToCrm — только заявка «на этот день», строкам
// visit_id не ставил, и зеркало их дублировало; наутро обход доски уносил
// ОПЛАТИВШЕГО пациента в «Не пришёл»). Теперь шаг один, его зовут все двери
// записи и регистрации (docs/specs/2026-10-09-crm-unify-design.md).
//
// ПРАВИЛО:
//   A. строки заявок пациента на ЭТОТ день (или без даты), не занятые живым
//      визитом, берут этот визит — зеркало (mirrorVisit) после этого находит
//      их, а не заводит вторые;
//   B. заявка, которая уже держит этот визит (строками или привязкой);
//   C. открытые заявки пациента, которые ЖДУТ этот приход: без ждущих строк,
//      или с датой / строкой на этот день — любой роли, любой давности;
//   D. ни одной — по телефону: открытая заявка БЕЗ пациента, тот же phoneKey,
//      и он у ОДНОЙ карты (phone и phone_secondary). Пишется ТОЛЬКО
//      patient_id и ступень: ни строк, ни visit_id, ни привязки — общий
//      семейный номер не переносит услуги на чужой счёт;

import { openStageKeys, scheduledStageKey, SEED_NO_SHOW_STAGE } from './config.js';
import { visitRow, requestOfVisit, isCallcenterUser, PRE_ARRIVAL } from './booking-mirror.js';
import { phoneKey, phoneLikePattern } from '../../../public/js/admin/views/crm-phone-match.js';

// До окна повторного обращения (задача 6) колл-центр по-прежнему берёт заявку
// не старше 30 дней — то же, что attachVisitToCrm.
export const CALLCENTER_ATTACH_DAYS = 30;
export const MIN_PHONE_KEY_DIGITS = 7;
const NOW_SQL = "strftime('%Y-%m-%dT%H:%M:%SZ','now')";
const holes = (a) => a.map(() => '?').join(',');

/** Карты пациентов с этим ключом номера — в phone ИЛИ phone_secondary. */
export function patientIdsWithPhoneKey(db, key) {
  if (!key || key.length < MIN_PHONE_KEY_DIGITS) return [];
  const like = phoneLikePattern(key);
  return db.prepare('SELECT id, phone, phone_secondary FROM patients WHERE phone LIKE ? OR phone_secondary LIKE ?')
    .all(like, like)
    .filter((p) => phoneKey(p.phone || '') === key || phoneKey(p.phone_secondary || '') === key)
    .map((p) => Number(p.id));
}

function patientPhoneKeys(db, patientId) {
  const p = db.prepare('SELECT phone, phone_secondary FROM patients WHERE id = ?').get(patientId);
  if (!p) return [];
  return [...new Set([p.phone, p.phone_secondary].map((x) => phoneKey(x || ''))
    .filter((k) => k.length >= MIN_PHONE_KEY_DIGITS))];
}

/** Ждёт ли заявка ЭТОТ приход: без ждущих строк, или дата / строка на этот день (или без даты). */
export function waitsForDay(db, requestId, day) {
  return !!db.prepare(`
    SELECT 1 FROM crm_requests r
     WHERE r.id = ?
       AND (NOT EXISTS (SELECT 1 FROM crm_request_services l WHERE l.request_id = r.id AND l.status = 'pending')
            OR date(r.scheduled_date) = date(?)
            OR EXISTS (SELECT 1 FROM crm_request_services l
                        WHERE l.request_id = r.id AND l.status = 'pending'
                          AND (l.scheduled_date IS NULL OR l.scheduled_date = '' OR date(l.scheduled_date) = date(?))))`)
    .get(requestId, day, day);
}

/** Открытые заявки без пациента с номером этого пациента — только если номер у ОДНОЙ карты. */
export function phoneLeadsFor(db, patientId, open) {
  if (!open.length) return [];
  const out = [];
  for (const key of patientPhoneKeys(db, patientId)) {
    const owners = patientIdsWithPhoneKey(db, key);
    if (owners.length !== 1 || owners[0] !== Number(patientId)) continue;
    const rows = db.prepare(`SELECT id, phone FROM crm_requests
                              WHERE patient_id IS NULL AND phone LIKE ? AND status IN (${holes(open)})
                              ORDER BY updated_at DESC, id DESC`).all(phoneLikePattern(key), ...open);
    for (const r of rows) if (phoneKey(r.phone || '') === key && !out.includes(r.id)) out.push(r.id);
  }
  return out;
}

/**
 * Связать визит с CRM. Ничего не возвращает (см. шапку) и не бросает.
 * @param {object} db
 * @param {number} visitId
 * @param {object} user — тот, кто записал (роль решает только шаг E)
 */
export function crmLinkVisit(db, visitId, user) {
  try {
    const v = visitRow(db, visitId);
    if (!v || v.sync_origin != null || !v.patient_id || !PRE_ARRIVAL.includes(v.status)) return;
    db.transaction(() => linkTx(db, v, user))();
  } catch (e) {
    console.error('[crm-link] визит', visitId, 'не связан с заявкой:', e && e.message);
  }
}

function linkTx(db, v, user) {
  const open = openStageKeys(db);
  if (!open.length) return;
  const uid = user && Number(user.id) > 0 ? Number(user.id) : null;
  const callcenter = isCallcenterUser(user);
  const touched = new Map();   // request_id → 'lines' | 'held' | 'patient' | 'phone' | 'callcenter' | 'created'

  // A. Строки этого дня. «Не пришёл» (сидовая) в выборке: её строки можно
  //    записать заново, но ступень меняет только приход.
  const lookIn = [...new Set([...open, SEED_NO_SHOW_STAGE])];
  const mine = db.prepare(`SELECT id, status FROM crm_requests WHERE patient_id = ? AND status IN (${holes(lookIn)})
                            ORDER BY updated_at DESC, id DESC`).all(v.patient_id, ...lookIn);
  const linkLines = db.prepare(`
    UPDATE crm_request_services SET visit_id = ?
     WHERE request_id = ? AND status = 'pending'
       AND (visit_id IS NULL OR NOT EXISTS (SELECT 1 FROM visits x WHERE x.id = crm_request_services.visit_id
                                                AND x.status NOT IN ('cancelled', 'no_show')))
       AND (scheduled_date IS NULL OR scheduled_date = '' OR date(scheduled_date) = date(?))`);
  for (const r of mine) if (linkLines.run(v.id, r.id, v.day).changes) touched.set(r.id, 'lines');

  // B. Заявка, которая уже держит визит.
  const held = requestOfVisit(db, v.id);
  if (held && !touched.has(held)) touched.set(held, 'held');

  // C. Открытые заявки пациента, ждущие этот приход.
  for (const r of mine) {
    if (touched.has(r.id) || !open.includes(r.status)) continue;
    if (waitsForDay(db, r.id, v.day)) touched.set(r.id, 'patient');
  }

  // D. По телефону — только patient_id.
  if (!touched.size) {
    for (const id of phoneLeadsFor(db, v.patient_id, open)) {
      if (!waitsForDay(db, id, v.day)) continue;
      db.prepare(`UPDATE crm_requests SET patient_id = ?, updated_at = ${NOW_SQL} WHERE id = ? AND patient_id IS NULL`)
        .run(v.patient_id, id);
      touched.set(id, 'phone');
    }
  }

  // E. Колл-центр: свежая открытая или новая.
  if (!touched.size && callcenter) {
    const recent = db.prepare(`SELECT id FROM crm_requests WHERE patient_id = ? AND status IN (${holes(open)})
                                 AND created_at >= strftime('%Y-%m-%dT%H:%M:%SZ','now','-${CALLCENTER_ATTACH_DAYS} days')
                               ORDER BY created_at DESC, id DESC LIMIT 1`).get(v.patient_id, ...open);
    if (recent) touched.set(recent.id, 'callcenter');
    else {
      const p = db.prepare('SELECT full_name, phone FROM patients WHERE id = ?').get(v.patient_id) || {};
      const id = Number(db.prepare(`INSERT INTO crm_requests (full_name, phone, source, status, patient_id, assigned_to, created_by, scheduled_date)
                                    VALUES (?, ?, 'call', ?, ?, ?, ?, ?)`)
        .run(p.full_name || '—', p.phone || '', scheduledStageKey(db) || open[0], v.patient_id, uid, uid, v.day).lastInsertRowid);
      touched.set(id, 'created');
    }
  }

  // F. Привязка записи — для C и E (A держит визит строками, D — только пациент).
  if (!held) {
    const pick = [...touched].find(([, via]) => via === 'patient' || via === 'callcenter' || via === 'created');
    if (pick) {
      db.prepare(`INSERT OR REPLACE INTO crm_booking_links (visit_id, request_id, source, created_by, created_request)
                  VALUES (?, ?, ?, ?, ?)`)
        .run(v.id, pick[0], callcenter ? 'callcenter' : 'match', uid, pick[1] === 'created' ? 1 : 0);
    }
  }

  // G. Ступень и дата — только живым и только вперёд.
  const scheduled = scheduledStageKey(db);
  const schedAt = scheduled ? open.indexOf(scheduled) : -1;
  const read = db.prepare('SELECT id, status, scheduled_date FROM crm_requests WHERE id = ?');
  const write = db.prepare(`UPDATE crm_requests SET status = ?, scheduled_date = ?, updated_at = ${NOW_SQL} WHERE id = ?`);
  for (const [id, via] of touched) {
    if (via === 'created') continue;
    const r = read.get(id);
    if (!r || !open.includes(r.status)) continue;
    const at = open.indexOf(r.status);
    const status = (schedAt >= 0 && at >= 0 && at < schedAt) ? scheduled : r.status;
    const was = String(r.scheduled_date || '').trim().slice(0, 10);
    const when = (!was || was > v.day) ? v.day : was;
    if (status === r.status && when === r.scheduled_date) continue;
    write.run(status, when, id);
    try {
      db.prepare(`INSERT INTO crm_booking_undo (visit_id, request_id, prev_status, prev_scheduled_date, set_status, set_scheduled_date)
                  VALUES (?, ?, ?, ?, ?, ?)`).run(v.id, id, r.status, r.scheduled_date ?? null, status, when);
    } catch { /* сборка без 186 — возвращать будет нечего */ }
  }
  try { db.prepare("DELETE FROM crm_booking_undo WHERE created_at < strftime('%Y-%m-%dT%H:%M:%SZ','now','-1 day')").run(); }
  catch { /* сборка без 186 */ }
}
```

// CRM_UNIFY_V1 (2026-10-09) — «КОЛОНКА ЗАПИСИ»: ОДНО ПРАВИЛО ДЛЯ СЕРВЕРА И БРАУЗЕРА.
//
// Куда переходит карточка, когда пациента ЗАПИСАЛИ. Это открытая видимая
// колонка ДО «Пришёл» (колонки-конверсии): по умолчанию «Записан», если она
// есть и видна, иначе последняя такая; выбор администратора в «CRM-канбан» —
// если он всё ещё допустим. Раньше сервер и браузер угадывали по-разному, и у
// клиники записанные уезжали в «Успешно».
//
// Чистая функция: без базы, без DOM. Сервер (services/crm/config.js
// scheduledStageKey) и экран (crm-settings-logic.js boardConfig) зовут её.
export const SEED_BOOKED_STAGE = 'scheduled';

const isActive = (s) => (s.is_active === undefined || s.is_active === null ? true : !!Number(s.is_active) || s.is_active === true);

/** Ключи колонок, которые могут быть «Колонкой записи», по порядку доски. */
export function bookedStageCandidates(stages) {
  const list = (Array.isArray(stages) ? stages : []).filter((s) => s && s.key)
    .slice().sort((a, b) => (Number(a.position) || 0) - (Number(b.position) || 0) || String(a.key).localeCompare(String(b.key)));
  const wonAt = list.findIndex((s) => s.kind === 'won');
  const before = wonAt >= 0 ? list.slice(0, wonAt) : list;
  return before.filter((s) => s.kind === 'open' && isActive(s)).map((s) => s.key);
}

/** «Колонка записи»: выбор, если допустим; иначе «Записан»; иначе последняя кандидатка; null — некуда. */
export function bookedStageKey(stages, chosen = null) {
  const c = bookedStageCandidates(stages);
  if (chosen && c.includes(chosen)) return chosen;
  if (c.includes(SEED_BOOKED_STAGE)) return SEED_BOOKED_STAGE;
  return c.length ? c[c.length - 1] : null;
}

// CRM_UNIFY_V1 (2026-10-09) — «НЕ ПРИШЁЛ» СТАВИТ СЕРВЕР.
//
// Дизайн: «запись прошла, визит не начат, не оплачен, не отмечен». Раньше это
// делал браузер при каждой загрузке доски (views/crm.js CRM_AUTO_NOSHOW_V1) по

// ПРАВИЛО (только однозначные случаи):
//   • только в сидовую «Не пришёл» — как отметка «Не пришёл» в календаре
//     (visit-status.js): первая проигрышная колонка может быть «Отказ»;
//   • карточка С ЗАПИСЬЮ (визит держат её ждущие строки или crm_booking_links):
//     все живые записи в прошлом, ни у одной нет доказательства прихода
//     (отметка, деньги, работа, закрытые строки, талон, товар —
//     arrivedByEvidence), и в эти дни пациент не пришёл другим визитом;
//   • карточка «НА ДАТУ» без записи: только из «Колонки записи» и дальше,
//     только с пациентом, и только если в этот день у пациента нет визита с
//     доказательством. Без пациента проверить нечем — не трогаем;
//   • «Перезвонить» и всё до «Колонки записи» — работа оператора, не трогаем.
// Статус ВИЗИТА не меняется — только карточка. Предоплата мешает «Не пришёл»,
// но приходом не считается (это решает visit-status.js).
//
// Синхронизация зданий: запись в соседнее здание живёт здесь своим визитом;
// приход там доезжает порцией и через crmFromSync поднимает «Не пришёл» в
// «Пришёл» (правило прихода, visit-status.js). Задержка канала исправляется сама.
//
// Не бросает: ошибка — в лог.
import { openStageKeys, noShowStageKey, scheduledStageKey, SEED_NO_SHOW_STAGE } from './config.js';
import { arrivedByEvidence } from './booking-mirror.js';
import { localDate, today } from '../domain/day.js';

const holes = (a) => a.map(() => '?').join(',');

/** Один проход. Возвращает id карточек, ушедших в «Не пришёл». */
export function crmNoShowSweep(db, { day = null } = {}) {
  const moved = [];
  try {
    if (noShowStageKey(db) !== SEED_NO_SHOW_STAGE) return moved;
    const open = openStageKeys(db);
    if (!open.length) return moved;
    const d0 = day || today(db);
    const booked = scheduledStageKey(db);
    const waiting = booked && open.includes(booked) ? open.slice(open.indexOf(booked)) : [];
    const leads = db.prepare(`SELECT id, status, patient_id, scheduled_date FROM crm_requests WHERE status IN (${holes(open)})`).all(...open);
    const bookingsOf = db.prepare(`
      SELECT v.id, v.status, ${localDate('v.visit_date')} AS day FROM visits v
       WHERE v.id IN (SELECT visit_id FROM crm_request_services
                       WHERE request_id = ? AND status = 'pending' AND visit_id IS NOT NULL
                      UNION SELECT visit_id FROM crm_booking_links WHERE request_id = ?)
         AND v.status IN ('scheduled', 'confirmed', 'arrived')`);
    const dayVisits = db.prepare(`SELECT id, status FROM visits
                                   WHERE patient_id = ? AND ${localDate('visit_date')} = ? AND status NOT IN ('cancelled', 'no_show')`);
    const cameOn = (pid, d) => !!pid && dayVisits.all(pid, d).some((x) => x.status === 'arrived' || arrivedByEvidence(db, x.id));
    const write = db.prepare(`UPDATE crm_requests SET status = ?, updated_at = strftime('%Y-%m-%dT%H:%M:%SZ','now')
                               WHERE id = ? AND status = ?`);
    db.transaction(() => {
      for (const L of leads) {
        if (L.status === SEED_NO_SHOW_STAGE) continue;
        let books = [];
        try { books = bookingsOf.all(L.id, L.id); } catch { books = []; }   // сборка без 187
        let miss = false;
        if (books.length) {
          miss = books.every((b) => b.day < d0 && b.status !== 'arrived' && !arrivedByEvidence(db, b.id))
            && !books.some((b) => cameOn(L.patient_id, b.day));
        } else if (waiting.includes(L.status) && L.patient_id) {
          const d = String(L.scheduled_date || '').slice(0, 10);
          miss = !!d && d < d0 && !cameOn(L.patient_id, d);
        }
        if (miss && write.run(SEED_NO_SHOW_STAGE, L.id, L.status).changes) moved.push(L.id);
      }
    })();
  } catch (e) {
    console.error('[crm-no-show] проход не выполнен:', e && e.message);
  }
  return moved;
}

/** При запуске и раз в час. Таймер unref: остановке сервера не мешает. */
export function scheduleCrmNoShow(db, { everyMs = 3600 * 1000 } = {}) {
  crmNoShowSweep(db);
  const h = setInterval(() => crmNoShowSweep(db), everyMs);
  if (h && typeof h.unref === 'function') h.unref();
  return h;
}

// CRM_UNIFY_V1 (2026-10-09) — ОКНО ПОВТОРНОГО ОБРАЩЕНИЯ (решение владельца 4).
//
// Звонок или новая запись в пределах окна от ПОСЛЕДНЕГО ДВИЖЕНИЯ карточки
// (updated_at — его двигает каждый писатель карточки) — та же карточка. После
// окна открытая карточка возвращается в начало воронки (одна карточка, история
// внутри), закрытая — заводится новая с тем же пациентом. Приход на уже
// назначенную запись — не новое обращение, окно его не касается
// (crm/visit-link.js, crm/visit-status.js). Окно — настройка «CRM-канбан»
// (crm_settings.window_hours, по умолчанию 72).
//
// Одно правило, одна функция: её зовут звонок (lead-from-call.js) и запись
// (visit-link.js). Исходящий звонок — работа оператора, окно его не касается.
import { openStageKeys, readCrmSettings } from './config.js';

const HOUR = 3600 * 1000;

export function windowHours(db) { return readCrmSettings(db).window_hours; }

export function lastActivityMs(lead) {
  const t = Date.parse((lead && (lead.updated_at || lead.created_at)) || '');
  return Number.isNaN(t) ? 0 : t;
}

export function withinWindow(lead, hours, now = Date.now()) {
  return lastActivityMs(lead) >= now - hours * HOUR;
}

/** Первая открытая видимая колонка — начало воронки («Новый лид» у клиники). */
export function firstStageKey(db) {
  try {
    const r = db.prepare("SELECT key FROM crm_stages WHERE kind = 'open' AND is_active = 1 ORDER BY position, key LIMIT 1").get();
    if (r) return r.key;
  } catch { /* справочник не читается */ }
  return openStageKeys(db)[0] || null;
}

/** Вернуть открытую карточку в начало: новое обращение после окна. */
export function reopenLead(db, id) {
  const first = firstStageKey(db);
  const open = openStageKeys(db);
  if (!first || !open.length) return;
  db.prepare(`UPDATE crm_requests SET status = ?, updated_at = strftime('%Y-%m-%dT%H:%M:%SZ','now')
               WHERE id = ? AND status IN (${open.map(() => '?').join(',')})`).run(first, id, ...open);
}

/**
 * Решение по новому обращению человека.
 * @param {object[]} leads — ВСЕ его карточки (любые ступени), с updated_at/created_at
 * @returns {{lead: object|null, action: 'same'|'reopen'|'closed'|'new'}}
 */
export function contactDecision(db, leads, { now = Date.now() } = {}) {
  const hours = windowHours(db);
  const open = new Set(openStageKeys(db));
  const sorted = [...(leads || [])].sort((a, b) => lastActivityMs(b) - lastActivityMs(a) || b.id - a.id);
  const live = sorted.find((l) => open.has(l.status));
  if (live) return { lead: live, action: withinWindow(live, hours, now) ? 'same' : 'reopen' };
  const last = sorted[0];
  if (last && withinWindow(last, hours, now)) return { lead: last, action: 'closed' };
  return { lead: null, action: 'new' };
}

// граница — начало МЕСТНЫХ суток, неделя — с понедельника, «по» — включая весь день.
export function periodStart(key, now = new Date()) {
    if (key === 'all') return null;
    const d = new Date(now); d.setHours(0, 0, 0, 0);
    if (key === 'today') return d;
    if (key === 'week') { d.setDate(d.getDate() - ((d.getDay() + 6) % 7)); return d; }
    d.setDate(d.getDate() - (Number(key) - 1));
    return d;
}
export function dayStart(ymd) { if (!ymd) return null; const d = new Date(ymd + 'T00:00:00'); return isNaN(d) ? null : d; }
export function dayEnd(ymd) { if (!ymd) return null; const d = new Date(ymd + 'T23:59:59.999'); return isNaN(d) ? null : d; }

/** Границы created_at для загрузки закрытых: ISO или null с каждой стороны. */
export function periodBounds(period, customFrom = '', customTo = '', now = new Date()) {
    if (period === 'custom') {
        const f = dayStart(customFrom), t = dayEnd(customTo);
        return { from: f ? f.toISOString() : null, to: t ? t.toISOString() : null };
    }
    const s = periodStart(period || 'all', now);
    return { from: s ? s.toISOString() : null, to: null };
}

/** Фильтр «Оператор»: 'all' | 'me' | 'none' | id. */
export function withOperator(q, operator, me) {
    if (operator === 'me') return me != null ? q.eq('assigned_to', me) : q;
    if (operator === 'none') return q.is('assigned_to', null);
    if (operator != null && operator !== 'all' && Number(operator) > 0) return q.eq('assigned_to', Number(operator));
    return q;
}

/**
 * @returns {Promise<{rows: object[], counts: Object<string, number>, capped: Object<string, boolean>, error?: object}>}
 */
export async function loadBoard({ db = supabase, openKeys = [], closedKeys = [], bounds = { from: null, to: null }, operator = 'all', me = null } = {}) {
    const byId = new Map();
    const add = (rows) => { for (const r of rows || []) if (r && r.id != null) byId.set(String(r.id), r); };
    const counts = {};
    const capped = {};
    if (openKeys.length) {
        const res = await withOperator(db.from('crm_requests').select(BOARD_SELECT).in('status', openKeys), operator, me)
            .order('id', { ascending: false });
        if (res.error) return { rows: [], counts, capped, error: res.error };
        add(res.data);
    }
    if (closedKeys.length) {
        if (bounds.from || bounds.to) {
            let q = db.from('crm_requests').select(BOARD_SELECT).in('status', closedKeys);
            if (bounds.from) q = q.gte('created_at', bounds.from);
            if (bounds.to) q = q.lte('created_at', bounds.to);
            const res = await withOperator(q, operator, me).order('id', { ascending: false });
            if (res.error) return { rows: [], counts, capped, error: res.error };
            add(res.data);
        } else {
            for (const k of closedKeys) {
                const res = await withOperator(db.from('crm_requests').select(BOARD_SELECT).eq('status', k), operator, me)
                    .order('id', { ascending: false }).limit(CLOSED_ALL_TIME_LIMIT);
                if (res.error) return { rows: [], counts, capped, error: res.error };
                add(res.data);
                if ((res.data || []).length >= CLOSED_ALL_TIME_LIMIT) {
                    const c = await withOperator(db.from('crm_requests').select('id', { count: 'exact' }).eq('status', k), operator, me).limit(1);
                    if (!c.error && Number.isFinite(Number(c.count))) { counts[k] = Number(c.count); capped[k] = true; }
                }
            }
        }
    }
    return { rows: [...byId.values()].sort((a, b) => Number(b.id) - Number(a.id)), counts, capped };
}

export function moveTasksWithLead(db, requestId, { from = null, to = null } = {}) {
  const t = to == null || to === '' ? null : Number(to);
  const f = from == null || from === '' ? null : Number(from);
  if (t == null || t === f) return 0;
  return db.prepare(`UPDATE crm_tasks SET assignee_id = ?
                      WHERE request_id = ? AND done_at IS NULL AND (assignee_id IS NULL OR assignee_id = ?)`)
    .run(t, requestId, f == null ? -1 : f).changes;
}

const USER_COLS = 'id, username, full_name, role, extra_roles, custom_role_code, department_id, is_active, must_change_password';
function userById(db, id) {
  const r = db.prepare(`SELECT ${USER_COLS} FROM users WHERE id = ?`).get(id);
  return r ? publicUser(r) : null;

const boardUser = (u) => !!u && u.is_active && canRead('crm_tasks', effectiveRoles(u));

/** Видит ли сотрудник карточку с этим хозяином. */
export function userSeesLead(db, userId, assignedTo) {
  const u = userById(db, userId);
  return boardUser(u) && leadVisible(db, u, assignedTo);
}

/** Отказ /api/db (вставка и правка crm_tasks с assignee_id) или null. */
export function taskAssigneeRefusal(db, meta, body, user) {
  if (!meta || meta.table !== 'crm_tasks' || (meta.op !== 'insert' && meta.op !== 'update')) return null;
  const rows = Array.isArray(body && body.values) ? body.values : [body && body.values];
  const named = rows.filter((r) => r && Object.prototype.hasOwnProperty.call(r, 'assignee_id') && r.assignee_id != null && r.assignee_id !== '');
  if (!named.length) return null;
  let pairs;
  if (meta.op === 'insert') pairs = named.map((r) => [Number(r.request_id), Number(r.assignee_id)]);
  else {
    const sel = compile({ table: 'crm_tasks', op: 'select', columns: 'id, request_id', filters: body.filters }, user, { db });
    pairs = db.prepare(sel.sql).all(...sel.params).map((x) => [Number(x.request_id), Number(named[0].assignee_id)]);
  }
  for (const [rid, who] of pairs) {
    const lead = db.prepare('SELECT assigned_to FROM crm_requests WHERE id = ?').get(rid);
    if (!lead) continue;   // заявки нет — откажет ограничение через родителя
    if (!userSeesLead(db, who, lead.assigned_to)) {
      return 'Ответственным можно назначить только того, кто видит эту карточку: её оператора или руководителя.';
    }
  }
  return null;
}

/** RPC crm_task_assignees { request_id } → [{ id, full_name }]: кого можно назначить. */
export function crmTaskAssignees(db, args, user) {
  if (!canRead('crm_tasks', effectiveRoles(user))) throw new RpcError('Задачи CRM вам недоступны.', 403);
  const rid = Number(args && args.request_id);
  const lead = Number.isInteger(rid) && rid > 0 ? db.prepare('SELECT assigned_to FROM crm_requests WHERE id = ?').get(rid) : null;
  // Чужая карточка отвечает пустым списком — как несуществующая.
  if (!lead || !leadVisible(db, user, lead.assigned_to)) return [];
  return db.prepare(`SELECT ${USER_COLS} FROM users WHERE is_active = 1 ORDER BY full_name`).all()
    .map(publicUser).filter((u) => boardUser(u) && leadVisible(db, u, lead.assigned_to))
    .map((u) => ({ id: u.id, full_name: u.full_name }));
}

- Потерянные открытые задачи → текущему оператору карточки.

**Однозначный случай карточки:**
- карточка в живой колонке или в сидовой «Не пришёл», с пациентом и с датой не позже сегодня;

  - отметка «Пришёл»;

// CRM_UNIFY_V1 (2026-10-09) — РАЗОВОЕ ИСПРАВЛЕНИЕ (решение владельца 5).
//
// До CRM_UNIFY_V1 карточки застревали: оплативший пациент оставался в
// «Записан» или уезжал в «Не пришёл» (обход доски не видел денег), задача
// оставалась у оператора, которому карточку уже не видно. Исправляем ОДИН раз,
// при первом запуске после миграции 238, и только однозначные случаи:
//   • карточка: в живой колонке или сидовой «Не пришёл», с пациентом и датой не
//     позже сегодня; в этот день у пациента живой визит с отметкой прихода, с
//     платежом в день визита или позже (не предоплата), с работой над услугой
//     или со счётом, выставленным в тот же день (так регистрирует стойка) →
//     «Пришёл». Карточки без пациента не трогаются — их дня записи нет;
//   • задача: открыта, карточка с оператором, исполнителя нет или он карточку
//     не видит (правило доски, crm/tasks-follow.js userSeesLead) → оператору.
// Меняются ТОЛЬКО crm_requests.status и crm_tasks.assignee_id. Счета, платежи,
// строки услуг и визиты — нет. Каждое изменение — в crm_unify_repair_log.
import { openStageKeys, wonStageKey, SEED_NO_SHOW_STAGE } from './config.js';
import { EVIDENCE_SERVICE_STATUSES } from './visit-status.js';
import { localDate, today } from '../domain/day.js';
import { userSeesLead } from './tasks-follow.js';

const NOW_SQL = "strftime('%Y-%m-%dT%H:%M:%SZ','now')";

export function crmUnifyRepair(db, { day = null } = {}) {
  const out = { stages: 0, tasks: 0, skipped: false };
  let mark;
  try { mark = db.prepare('SELECT done_at FROM crm_unify_repair WHERE id = 1').get(); }
  catch { out.skipped = true; return out; }
  if (!mark || mark.done_at) { out.skipped = true; return out; }
  const d0 = day || today(db);
  const open = openStageKeys(db);
  const won = wonStageKey(db);
  const from = [...new Set([...open, SEED_NO_SHOW_STAGE])];
  const marks = EVIDENCE_SERVICE_STATUSES.map(() => '?').join(',');
  const log = db.prepare('INSERT INTO crm_unify_repair_log (kind, row_id, from_value, to_value) VALUES (?, ?, ?, ?)');
  db.transaction(() => {
    const leads = db.prepare(`SELECT id, status, patient_id, scheduled_date FROM crm_requests
                               WHERE patient_id IS NOT NULL AND status IN (${from.map(() => '?').join(',')})
                                 AND scheduled_date IS NOT NULL AND scheduled_date <> '' AND date(scheduled_date) <= date(?)`)
      .all(...from, d0);
    const came = db.prepare(`
      SELECT 1 FROM visits v
       WHERE v.patient_id = ? AND ${localDate('v.visit_date')} = date(?) AND v.status NOT IN ('cancelled', 'no_show')
         AND (v.status = 'arrived'
              OR EXISTS (SELECT 1 FROM invoices i JOIN payments p ON p.invoice_id = i.id
                          WHERE i.visit_id = v.id AND ${localDate('p.paid_at')} >= date(?))
              OR EXISTS (SELECT 1 FROM visit_services vs WHERE vs.visit_id = v.id AND vs.status IN (${marks}))
              OR EXISTS (SELECT 1 FROM invoices i WHERE i.visit_id = v.id AND ${localDate('i.created_at')} = date(?)))
       LIMIT 1`);
    const setWon = db.prepare(`UPDATE crm_requests SET status = ?, updated_at = ${NOW_SQL} WHERE id = ? AND status = ?`);
    for (const L of leads) {
      const d = String(L.scheduled_date).slice(0, 10);
      if (!came.get(L.patient_id, d, d, ...EVIDENCE_SERVICE_STATUSES, d)) continue;
      if (setWon.run(won, L.id, L.status).changes) { log.run('stage', L.id, L.status, won); out.stages++; }
    }
    const tasks = db.prepare(`SELECT t.id, t.assignee_id, r.assigned_to FROM crm_tasks t JOIN crm_requests r ON r.id = t.request_id
                               WHERE t.done_at IS NULL AND r.assigned_to IS NOT NULL
                                 AND (t.assignee_id IS NULL OR t.assignee_id <> r.assigned_to)`).all();
    const setTask = db.prepare('UPDATE crm_tasks SET assignee_id = ? WHERE id = ?');
    for (const t of tasks) {
      if (t.assignee_id != null && userSeesLead(db, t.assignee_id, t.assigned_to)) continue;   // видит — не потеряна
      setTask.run(t.assigned_to, t.id);
      log.run('task', t.id, t.assignee_id == null ? null : String(t.assignee_id), String(t.assigned_to));
      out.tasks++;
    }
    db.prepare(`UPDATE crm_unify_repair SET done_at = ${NOW_SQL}, stages = ?, tasks = ? WHERE id = 1`).run(out.stages, out.tasks);
  })();
  return out;
}
```

1. **Какую колонку поставить «Колонкой записи» у клиники Farhod Madad Shifo?**
