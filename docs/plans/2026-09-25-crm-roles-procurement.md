# Руководитель колл-центра, слияние дублей, метки CRM; отчёты и настройки по ролям; фильтры закупок (2026-09-25)

Владелец: «in the roles: fix adding an operator option (e.g. head of call centre) and merge duplicates;
adding tags to the cards of the crm; an option to read a report per section for roles; in the settings
per section and per subsection for the roles; in procurement filters for category so users can filter
based off their responsibilities, and in the expiration date similar filters; fix the padding of my
stock».

## Решения владельца (25.09)
- Руководитель колл-центра — галочка в «Ролях» «Видит все заявки и передаёт их» (ключ `crm.all`) для
  любой роли: видит все карточки, передаёт их, видит показатели операторов и просроченные задачи всей
  команды; удалять карточки — только администратор.
- Отчёты в «Ролях» — около 7 групп: выручка и счета; касса; оплата врачей; рефералы; по услугам и
  рентабельность; закупки и склад; колл-центр. Существующие роли сохраняют нынешний доступ, пока их не
  сузят. Чужие выплаты видит только роль с группой «Оплата врачей»; своя выплата врача — всегда.
- Настройки — группы с разделами внутри; «Изменение» даёт настоящее право сохранять (сервер проверяет
  тот же ключ). Telegram, телефония, воронка CRM, API-ключи и «Роли» — только администратор.
- Категории закупок — фильтр, который каждый отмечает сам (запоминается за человеком); итоги и
  статистика на экране считаются по отмеченным категориям. Без назначения и без ограничений.

## Решено по умолчанию (сказано владельцу)
Слияние: список «Дубликаты» + «Объединить»; остаётся карточка, которую выбирает человек (заранее
выбрана самая продвинутая или с пациентом); услуги, задачи, заметки переезжают; разные пациенты на
одном номере — слияние запрещено; сливают администратор и `crm.all`. Метки — список в настройках CRM с
цветом, несколько на карточку, на доске, в карточке, фильтр доски, отчёт колл-центра и Excel. Отчёт
колл-центра считает заявки по тому, кто ведёт (`assigned_to`), с колонкой «кто создал».

## Пакеты
- **P3 PROCUREMENT_FILTERS_V1 + отступы** — фильтр категорий (Склад, Товары, Сроки годности, отчёт
  «Закупки и склад»), фильтр состояния сроков, отступы «Мои запасы», журнала и сроков.
- **P1 CRM_HEAD_MERGE_TAGS_V1** — `crm.all`, список операторов, отчёт по `assigned_to`, слияние, метки.
- **P2 ROLE_REPORTS_SETTINGS_V1** — отчёты по группам и настройки по разделам, с проверкой на сервере.
