# Заявки из «Моих запасов» и автозаявка по минимуму (STOCK_REQUEST_V1)

**Дата:** 2026-09-23 · **Владелец:** «#my-stock should be able to request and set to auto request with
minimum amount». Продолжение `2026-09-23-stock-flow.md`.

Решения владельца (четыре вопроса, выбран рекомендованный вариант в каждом):

1. **Сколько просит автозаявка** — до нормы: на товар два числа, «минимум» и «норма». Остаток упал
   ниже минимума → заявка на (норма − остаток − уже запрошено и не выдано).
2. **Кто одобряет** — кладовщик в «Заявках», как сейчас заявки отделов; одобрение выдаёт товар.
   Автозаявка сама ничего не выдаёт.
3. **Для кого** — человек просит себе; член отдела может просить и для отдела.
4. **Кто ставит минимумы** — каждый себе, заведующая — отделу, кладовщик и администратор — любому.

## Что есть сегодня

- `purchase_requisitions` (мигр. 028) знает только отдел (`department_id` обязателен в
  `create_requisition`); `approve_requisition_and_issue` выдаёт в подотчёт этого отдела.
- Личной заявки нет. Минимума на держателя нет — только `products.reorder_level` (склад).
- «Мои запасы» (`#my-stock`) только показывает.

## Задачи

- **R1 — сервер.** Миграция 145: у заявки держатель (`holder_type`, `holder_id`: staff/department) и
  признак автозаявки; таблица минимумов (держатель × товар: минимум, норма, кто и когда поставил), не
  уходит в синхронизацию зданий. RPC: поставить/снять минимум (права по решению 4), список минимумов
  (своё/отдел/всё), заявка для себя или отдела; одобрение выдаёт тому держателю, что в заявке.
  Автозаявка — одно место, через которое уменьшается подотчёт: остаток ниже минимума и открытой
  автозаявки на этот товар у этого держателя нет → заявка «подана» на недостающее до нормы. Та же
  проверка при установке минимума. Никогда не отказывает списанию.
- **R2 — экраны.** «Мои запасы»: кнопка «Запросить» (себе / для отдела), у каждой строки минимум и
  норма, добавить минимум на товар, которого ещё нет на руках; видно открытые заявки и пометку «авто».
  Карточка отдела: те же минимумы для заведующей. «Заявки» у кладовщика: для кого (сотрудник/отдел) и
  «авто».
- **R3 — ревью, слияние, установка на тестовую клинику** под следующим номером версии.
