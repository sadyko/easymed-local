# Три ступени доли врача и отметка «Внешняя лаборатория» (DOCTOR_TIER_V2 · EXTERNAL_LAB_V1)

**Дата:** 2026-09-23 · Миграция **147** (`147_tiers_external_lab.sql`), только ADD COLUMN.

## 1. Три ступени доли по объёму — DOCTOR_TIER_V2

**Владелец:** «in the services settings, we need to add another 2 (overall 3) steps of the percentage
for the service» (к полям «Порог, услуг в месяц» + «Доля выше порога» редактора услуги).

**Сегодня (DOCTOR_TIER_V1, миграция 140):** одна ступень на услуге — `doctor_tier_from` /
`doctor_tier_percent`. Нумерация строк врача по точной услуге за местный месяц — `TIER_RANK_SQL`
(`server/services/rpc/reports.js`), смесь процента — `ITEM_EFF_PCT_SQL`; кабинет повторяет её в
`tierShare()` по позициям `doctor_tier_positions`.

**Решения (правило «только выше порога» владельца сохраняется):**

- Ещё две пары колонок: `doctor_tier_from_2/percent_2`, `doctor_tier_from_3/percent_3` (типы и нули
  по умолчанию — как у 140). Нули = ступени нет, ни одна цифра не меняется.
- Строка, ушедшая за **самый высокий** из пройденных порогов, идёт по доле этой ступени (и никогда не
  ниже личного процента); до первого порога — личный процент. Фиксированная ставка (`fix`) — без
  ступеней. Строка с количеством > 1 делится по единицам между полосами.
- Пример: ступень 1 — 25 → 40 %, ступень 2 — 50 → 45 %, ступень 3 — 100 → 50 %: строки 1–25 по
  личному, 26–50 по 40 %, 51–100 по 45 %, 101+ по 50 %.
- Проверка (одно правило `tierStepsProblem` в `public/js/admin/service-editor-logic.js` — его зовут
  `service_save`, редактор и импорт Excel): каждая ступень парой; по порядку (нет ступени 3 без 2);
  пороги строго растут. Проценты расти не обязаны — о них ни слова. `TIER_RANK_SQL` дополнительно
  читает ступень 2/3 как «нет», если порядок нарушен (данные, пришедшие мимо проверок).
- Редактор: три ряда той же пары полей с подписями «Ступень 1/2/3».
- Кабинет: `tierShare()` делит по трём полосам (`units_above`, `units_above_2`, `units_above_3` из
  `doctor_tier_positions`); прогресс «N из M» идёт к **следующему** порогу, после последнего —
  «ступень действует».
- Excel: шесть колонок; для каждой ступени отдельно — нет заголовков → ступень не трогается,
  полупара → обнуляется с предупреждением; нарушенный порядок → со сломанной ступени и дальше не
  сохраняется, с предупреждением.
- Колонки едут с прайсом в филиалы (`branch-sync/catalogue.js`).

## 2. «Внешняя лаборатория» — EXTERNAL_LAB_V1

**Владелец:** «we need to tick the "внешняя лаборатория" so for the lab services which is provided in
the another clinic but result inputted in our system». На вопрос, что отметка меняет: «nothing, as it
is but labeled as external lab. then we will fetch the report from there», и «Just a tick, no lab
named».

**Решения:**

- `services.external_lab INTEGER NOT NULL DEFAULT 0`, едет с прайсом в филиалы.
- Галочка «Внешняя лаборатория» в редакторе услуги — только у группы «Лаборатория»
  (`services.type = 'lab'`, `labBlockVisible`). У не-лабораторной услуги `service_save` пишет 0;
  без ключа в запросе (старый клиент) значение при правке не меняется.
- Подпись «Внешняя лаборатория» там, где персонал видит лабораторную строку: список услуг, очередь
  лаборатории, окно ввода результатов, результаты анализов в карте пациента.
- **Больше ничего не меняется:** забор, штрихкод, анализатор, оплата, цены, печать — как сегодня.
- Excel: одна колонка `external_lab`; нет заголовка — отметка не трогается.
